# Desktop Duck 1.0.0

[English](../../README.md) · [Мастерская моделей и одежды](ART-TOOL.md)

Интерактивная утка для Omarchy Quattro и Hyprland: гуляет по краям окон,
ест корм, играет с мячом и реагирует на поглаживания. Есть классическая,
пиксельная и воксельная модели, три оперения, 12 головных уборов,
10 вариантов одежды и 14 готовых комплектов.

## Установка

```sh
omarchy plugin add https://github.com/ditrigo/omarchy-desktop-duck.git --enable
```

Для распакованного релиза или отдельной рабочей копии:

```sh
./install.sh
```

Постоянный ID — `ditrigo.desktop-duck`. Кнопка появляется справа на панели.
Установщик делает резервную копию и сохраняет настройки, имя и коллекцию.
Он не заменяет Git-установку из другой папки и не требует перезапуска оболочки.

## Управление

При первом запуске появляется жёлтая классическая утка, а справа на панели —
её кнопка. Звук изначально выключен. Через кнопку выберите модель, одежду и
поведение; настройки и память питомца сохраняются локально.

- Левая кнопка по значку или правая по утке — окно «Играть / Внешность / Поведение».
- Средняя кнопка — угостить; правая по значку — пауза и продолжение.
- Движение по голове — погладить; щелчок по крылу — помахать; по животу — рассмешить.
- Перетаскивание — поднять утку. Корм ставится щелчком; мяч бросается жестом.
- Esc закрывает окно или отменяет размещение. Ctrl+1/2/3 переключают вкладки.

Можно сохранять до 12 личных образов. Вкладка поведения содержит характер,
выбор монитора, любимое место, тихие часы, экономичный режим и уменьшение движения.
При блокировке и выключении экрана утка скрывается; скрытие за полноэкранными
приложениями настраивается отдельно. Звук по умолчанию выключен.

## Язык

Английский и русский следуют настройке **Omarchy → Setup → Language** и
переключаются без перезапуска. Остальные языки используют английский перевод.
Имена питомца, личные образы и подписи пользовательских ресурсов не переводятся.

## Обновление и удаление

```sh
omarchy plugin update ditrigo.desktop-duck
omarchy plugin disable ditrigo.desktop-duck
omarchy plugin enable ditrigo.desktop-duck
omarchy plugin remove ditrigo.desktop-duck
```

Перед заменой изменённой рабочей копии экспортируйте пользовательские пакеты.
Память питомца остаётся в `~/.local/state/omarchy-desktop-duck/`, резервные копии —
в её подпапке `backups/`. Удаление плагина не стирает эту память.

## Свои модели и одежда

Исходный релиз содержит инструмент `duck-art`:

```sh
./duck-art new model my-duck --label "Моя утка" --base vector
./duck-art new outfit my-coat --label "Моя одежда" --template raincoat
./duck-art preview my-coat --guides
./duck-art build --install
```

[Полная инструкция](ART-TOOL.md). Окружение Python хранится в кеше пользователя,
за пределами папки плагина. В установленную Git-копию нельзя записать снимок
из другой рабочей папки: запускайте мастерскую из самой установленной копии
или используйте отдельную установку для разработки.

## Зависимости и приватность

Для работы нужны Omarchy Quattro с `qs.Commons.Translations`, Quickshell,
Qt Quick и Hyprland. Для звука необязателен `pw-play` из `pipewire-audio`.
Python, uv, Node и Blender нужны для разработки и мастерской, а не для работы утки.

Плагин читает локальные координаты окон, курсора и экранов, хранит память
локально, не отправляет телеметрию и не использует сеть или повышенные права.
Код, исходная графика и Blender-модель распространяются по лицензии MIT.
